# Face_Roate 文件夹处理流程说明

## 📁 文件说明

`face_roate` 文件夹包含：
- **深度图**：`0.tiff_re.tiff`, `3.tiff_re.tiff`, `25.tiff_re.tiff`
- **RGB图像**：`f0.jpg`, `f3.jpg`, `f25.jpg`

## 🔄 完整处理流程

### 步骤1：深度图转点云

将深度图和RGB图像转换为PLY格式的点云文件。

**方法1：使用修改后的main.cpp程序**

需要修改 `point_cloud/main.cpp`，取消注释 `pointcloudFunc` 函数，或者创建一个新的处理函数。

**方法2：直接调用depth_io类**

创建一个简单的测试程序来处理这些文件。

### 步骤2：点云转网格

使用生成的 `*_rgb.ply` 文件生成网格模型。

### 步骤3：网格贴图

为网格模型生成纹理贴图，得到最终的3D模型。

## 📝 配置文件说明

### depth_to_pointcloud_config.cfg
用于深度图转点云的相机参数配置。

### mesh_config.cfg  
用于点云转网格的算法参数配置。

## ⚙️ 参数调整建议

根据实际数据调整配置文件中的参数：

1. **focus（焦距）**：根据相机参数调整
2. **step（视差步长）**：影响深度精度，通常0.01-0.03
3. **label（标签数量）**：根据深度图的最大值调整
4. **leafsize（体素大小）**：影响点云密度，越小越精细但越慢

## 🚀 快速开始

1. 确保文件命名匹配：
   - 深度图：`X.tiff_re.tiff`
   - RGB图：`fX.jpg`
   - 输出：`X_rgb.ply`

2. 运行深度图转点云程序

3. 运行点云转网格程序

4. 运行网格贴图程序
