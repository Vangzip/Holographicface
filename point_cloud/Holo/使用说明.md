# Holo 使用说明

## 项目功能介绍

Holo 是一个独立的全链路程序，用来把一组同名的深度图 TIFF 和彩色图 JPG 转成 3D OBJ，再从 OBJ 生成多视角图，最后根据多视角图生成 elemental 目标图像。

当前流程为：

```text
深度图 tiff + 彩色图 jpg
-> 彩色点云 ply
-> 网格 ply
-> 贴图 obj
-> 多视角 jpg
-> elemental 目标 jpg
```

Holo 已经把原来的 point_cloude、multiview、ImageTool9030/Generateimages 关键源码整合到一个项目里，不再通过外部 exe 串联调用。第三方库 OpenCV、PCL、VTK、OSG、osgEarth 仍然是必需依赖。

## 项目用法

推荐先运行微量功能测试。这个测试默认使用 `point_cloud\Holo\face_roate\0.tiff` 和 `point_cloud\Holo\face_roate\0.jpg`，输出到配置文件指定的相对目录。

在仓库根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File point_cloud\Holo\run_microtest.ps1
```

脚本会默认重新编译 `Release|x64`，清理配置里的 `output_root` 输出目录，然后运行完整链路。当前微测配置会生成：

```text
multiview: 3 * 3 = 9 张，每张 150 * 150 像素
elemental: 150 * 150 = 22500 张，每张 3 * 3 像素
```

手动运行 Holo：

```powershell
point_cloud\Holo\target\Holo.exe --config point_cloud\Holo\holo_config.microtest.ini --stage all
```

可选阶段：

```text
depth      深度图 + 彩色图 -> 点云 ply
mesh       点云 ply -> 网格 ply
model      网格 ply + 彩色图 -> 贴图 obj
multiview  obj -> 多视角 jpg
elemental  多视角 jpg -> elemental jpg
all        全链路
```

只检查配置和计划输出，不真正生成文件：

```powershell
point_cloud\Holo\target\Holo.exe --config point_cloud\Holo\holo_config.example.ini --dry-run
```

## 配置文件配置方法

主配置文件是：

```text
point_cloud\Holo\holo_config.microtest.ini
point_cloud\Holo\holo_config.example.ini
```

路径规则：相对路径都按配置文件所在目录解析；`multiview_out_dir` 和 `elemental_out_dir` 如果是相对路径，则按 `output_root` 解析。

常用配置：

```ini
depth_input_dir=face_roate

output_root=output\micro
multiview_out_dir=multiview
elemental_out_dir=elemental

multiview_angle=3
multiview_per=1
multiview_resolution=150

target_rows=150
target_cols=150
```

含义：

```text
depth_input_dir
输入目录，里面需要放同名的 .tiff 和 .jpg，例如 0.tiff + 0.jpg。

output_root
本次运行的输出根目录，建议用相对路径，例如 output\micro。

multiview_out_dir
多视角图输出目录。相对路径会放在 output_root 下面。

elemental_out_dir
最终目标图输出目录。相对路径会放在 output_root 下面。

multiview_angle * multiview_per
多视角行列数。例如 3 * 1 = 3，会生成 3 * 3 张多视角图。

multiview_resolution
每张多视角图的分辨率。例如 150 表示每张多视角图是 150 * 150。

target_rows * target_cols
最终 elemental 输出图数量。例如 150 * 150 = 22500 张。
```

Generateimages 阶段的每张输出图尺寸由多视角行列数决定。比如：

```ini
multiview_angle=30
multiview_per=9
multiview_resolution=150
target_rows=150
target_cols=150
```

结果是：

```text
multiview 生成 270 * 270 张图，每张 150 * 150 像素
elemental 生成 150 * 150 张图，每张 270 * 270 像素
```

## 移植说明

转移到其他设备时，优先保持目录结构不变：

```text
Holographicface
├─ opencv450
├─ PCL 1.12.1-rc1
├─ OSG365
├─ OE32
└─ point_cloud
   └─ Holo
```

需要确认或修改的地方：

```text
1. 第三方库路径
   point_cloud\HolographicfaceDependencies.props
   如果依赖目录不在仓库根目录旁边，修改 HolographicfaceThirdPartyRoot。

2. 编译环境
   使用 Visual Studio v142 工具集、x64 平台、Windows SDK 10.0.19041.0 或兼容版本。

3. 运行配置
   修改 holo_config*.ini 里的 depth_input_dir、output_root、multiview_out_dir、elemental_out_dir。
   建议继续使用相对路径，换机器时通常只需要调整输入目录和第三方库根路径。

4. 输入数据
   输入目录中每个样本需要同名 .tiff 和 .jpg。
   微量测试脚本默认只测试 0.tiff + 0.jpg。

5. 运行方式
   功能运行默认使用 Release|x64。
   Debug 可用于编译验证，但不建议直接跑全链路。
```
