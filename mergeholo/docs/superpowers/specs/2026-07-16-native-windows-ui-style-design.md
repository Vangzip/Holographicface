# MergeHolo Windows 原生界面统一设计

## 目标

以当前“打印配置”窗口使用的 Qt Widgets/Windows 原生控件为视觉基准，统一主窗口、“保存设置”和“打印配置”的桌面应用风格。移除主窗口和保存设置中的粗黑描边、无边框窗口及自绘圆形复选框，不改变处理、保存、打印、第二屏或控制卡行为。

## 视觉方向

- 在 Windows 上使用 Qt 的 `windowsvista` 原生样式；不可用时保留 Qt 当前系统样式。
- 使用系统调色板和系统控件状态，不用全局仿 Win32 QSS。
- 应用字体使用 `Microsoft YaHei UI`；字号保持桌面工具的常规密度，不使用随窗口宽度缩放的字号。
- 使用系统标题栏、标准窗口边框、标准方形复选框、标准按钮、标准进度条、分组框、标签页和表格。
- 卡片式背景、粗黑边框、无边框弹窗、自绘关闭按钮和圆形复选框全部移除。

## 主窗口

- 保留现有双预览、进度、状态和五个操作按钮的工作流与顺序。
- 预览区域改用标准 `QFrame` 面板边框，避免 2px 黑色描边叠加。
- 进度条恢复系统原生绘制。
- 底部按钮使用统一的标准高度和合理最小宽度，保留清晰中文命令文字；禁用、焦点、悬停和按下状态由系统样式绘制。
- 维持当前 860x560 基础窗口尺寸，同时允许布局在 Windows 100% 和 125% 缩放下正常伸缩且不重叠。

## 保存设置

- 恢复标准模态 `QDialog` 标题栏，标题为“保存设置”，由系统提供关闭按钮。
- 删除窗体内右上角自绘关闭按钮和相关代理样式。
- 三个选项使用标准 `QCheckBox`，仍支持任意组合。
- 底部使用标准“确定”和“取消”按钮布局。
- 保持既有语义：确定应用组合；取消、系统关闭、Esc 和 `reject()` 清空全部设置。

## 打印配置

- 保留图像源分组、参数标签页、运动轴表格、进度和状态区域。
- 不重新组织配置字段，不修改 runner、第二屏选择或控制卡接口。
- 仅统一窗口边距、控件间距和底部按钮尺寸，使其与主窗口和保存设置一致。
- 打印中按钮启用状态、取消和关闭行为保持不变。

## 公共样式边界

- 在应用入口集中选择 Windows 原生样式和字体，避免三个窗口各自维护重复 QSS。
- 窗口布局尺寸留在各自 `.ui` 文件中；只有无法由 Designer 属性表达的应用级样式选择放在 C++ 中。
- 不新增 Qt Quick、QML、Fluent 第三方库或图片资源。

## 行为与错误处理

- 本次只改变视觉和布局，不修改处理状态机、保存配置、时间戳目录、写盘失败警告、打印顺序、曝光关闭、回零或硬件错误处理。
- Windows 原生样式创建失败时继续使用 Qt 默认样式，不阻止程序启动。
- 保存设置所有拒绝路径继续清空选项；打印窗口关闭后再显示结果保存警告的顺序不变。

## 验证

- 扩展保存设置对话框测试，确认不再使用无边框窗口和自绘关闭按钮，并保持确定/取消/关闭语义。
- 运行保存持久化、保存设置、打印模块和 elemental 现有测试。
- 完整 Release 构建并链接 `mergeholo.exe`。
- 截取主窗口、保存设置和打印配置窗口，检查粗黑边框已移除、字体一致、按钮状态清楚，在 100% 和 125% 缩放下无文字截断或控件重叠。

## 非目标

- 不修改界面信息架构或增加新功能。
- 不修改打印配置字段、默认值或配置文件格式。
- 不修改第二屏、D3D11、VSync、控制卡 API、蛇形扫描、曝光和回零逻辑。
- 不清理或提交工作区中与本次样式统一无关的现有改动。
