# Holo 使用说明

Holo 是一个独立的全链路程序，用来把深度图和颜色图转换为点云、网格、贴图 OBJ、多视角图片，最后生成 elemental 目标图像。

## 输入要求

输入目录放在：

```text
D:\zp\Holographicface\point_cloud\Holo\face_roate
```

单个样本需要一对同名文件：

```text
0.tiff
0.jpg
```

当前微量功能测试只使用 `0` 这一组输入。测试脚本会检查目录里不要有其它 `.tiff` 输入；如果要只测 0，请删除或移走 `3.tiff`、`25.tiff` 这类其它输入。

## 一键微量功能测试

在仓库根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\zp\Holographicface\point_cloud\Holo\run_microtest.ps1
```

脚本会自动做这些事：

1. 强制 `Rebuild Release|x64`，避免误跑 Debug 产物。
2. 清空上一次的 `D:\zp\Holographicface\point_cloud\Holo\output\micro`。
3. 用 `face_roate\0.tiff` 和 `face_roate\0.jpg` 跑完整链路。
4. 检查输出数量和图片尺寸。

当前微测目标：

```text
multiview: 3 * 3 = 9 张，每张 150 * 150 像素
elemental: 150 * 150 = 22500 张，每张 3 * 3 像素
```

成功时会看到：

```text
[microtest] PASS: 0 input -> 9 multiview images 150x150 and 22500 elemental images 3x3
```

## 微测配置

配置文件：

```text
D:\zp\Holographicface\point_cloud\Holo\holo_config.microtest.ini
```

关键参数：

```ini
multiview_angle=3
multiview_per=1
multiview_resolution=150
view_rows=3
view_cols=3

target_rows=150
target_cols=150
elemental_block_images=750
```

含义：

```text
multiview_angle * multiview_per = 3
=> 生成 3 * 3 张 multiview 图

multiview_resolution = 150
=> 每张 multiview 图是 150 * 150 像素

target_rows * target_cols = 150 * 150
=> 生成 22500 张 elemental 图

view_rows * view_cols = 3 * 3
=> 每张 elemental 图是 3 * 3 像素
```

## 手动运行 Holo

如果不使用测试脚本，也可以手动运行：

```powershell
D:\zp\Holographicface\point_cloud\Holo\target\Holo.exe --config D:\zp\Holographicface\point_cloud\Holo\holo_config.microtest.ini --stage all
```

可选阶段：

```text
depth      深度图 + jpg -> 点云 ply
mesh       点云 ply -> mesh ply
model      mesh ply + jpg -> 贴图 obj
multiview  obj -> 多视角 jpg
elemental  multiview jpg -> elemental jpg
all        全部阶段
```

例如只跑 elemental：

```powershell
D:\zp\Holographicface\point_cloud\Holo\target\Holo.exe --config D:\zp\Holographicface\point_cloud\Holo\holo_config.microtest.ini --stage elemental
```

## Debug 和 Release

功能测试默认使用 `Release|x64`。

原因是当前第三方依赖主要按 Release 路径使用；Debug 可以用于编译检查，但不建议直接跑全链路。脚本会强制重建 Release，避免上一次 Debug 构建覆盖 `target\Holo.exe` 后误运行。

## 常见问题

如果测试脚本提示目录里有其它 `.tiff`：

```text
Microtest expects only 0.tiff in face_roate
```

请把 `face_roate` 里除 `0.tiff` 以外的测试输入移走或删除。

如果 multiview 或 elemental 数量不对，先删除：

```text
D:\zp\Holographicface\point_cloud\Holo\output\micro
```

然后重新运行 `run_microtest.ps1`。脚本本身也会自动清理这个目录。
