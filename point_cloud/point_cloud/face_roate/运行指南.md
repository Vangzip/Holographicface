# Face_Roate 文件夹处理运行指南

## 📋 文件说明

`face_roate` 文件夹包含：
- **深度图**：`0.tiff_re.tiff`, `3.tiff_re.tiff`, `25.tiff_re.tiff`
- **RGB图像**：`f0.jpg`, `f3.jpg`, `f25.jpg`

## 🔄 完整处理流程（三步）

### 步骤1：深度图转点云

将深度图和RGB图像转换为PLY格式的点云文件。

**命令行：**
```bash
程序名 -point face_roate文件夹路径 -config depth_to_pointcloud_config.cfg路径
```

**示例：**
```bash
point_cloud.exe  -point "D:\ljc\00code\3DFace\face_roate" -config "D:\ljc\00code\3DFace\face_roate\depth_to_pointcloud_config.cfg"
```

**输出文件：**
- `0_rgb.ply`
- `3_rgb.ply`
- `25_rgb.ply`

### 步骤2：点云转网格

使用生成的 `*_rgb.ply` 文件生成网格模型。

**命令行：**
```bash
程序名 -mesh face_roate文件夹路径 -config mesh_config.cfg路径
```

**示例：**
```bash
point_cloud.exe -mesh "D:\ljc\00code\3DFace\face_roate" -config "D:\ljc\00code\3DFace\face_roate\mesh_config.cfg"
```

**输出文件：**
- `0_mesh.ply`
- `3_mesh.ply`
- `25_mesh.ply`

### 步骤3：网格贴图

为网格模型生成纹理贴图，得到最终的3D模型。

**命令行：**
```bash
程序名 -model face_roate文件夹路径 -config mesh_config.cfg路径
```

**示例：**
```bash
point_cloud.exe -model "D:\ljc\00code\3DFace\face_roate" -config "D:\ljc\00code\3DFace\face_roatee\mesh_config.cfg"
```

**输出文件：**
- 带纹理的3D模型文件（通常是.obj格式）

## ⚙️ 配置文件参数说明

### depth_to_pointcloud_config.cfg（深度图转点云）

| 参数 | 说明 | 建议值 |
|------|------|--------|
| `disp` | 视差基线参数 | 1.0 |
| `step` | 视差步长 | 0.01-0.03 |
| `label` | 深度图最大标签值 | 根据实际数据调整 |
| `focus` | 焦距（毫米） | 根据相机参数调整 |
| `fdis` | 视差像素偏移差值 | 0.5 |

### mesh_config.cfg（点云转网格）

| 参数 | 说明 | 建议值 |
|------|------|--------|
| `reconstruct` | 重建算法：1=泊松，2=贪婪 | 1或2 |
| `kSearch` | K近邻搜索数量 | 20 |
| `searchradius` | 搜索半径 | 0.01 |
| `leafsize` | 体素滤波大小 | 0.001（0表示不滤波） |
| `holesize` | 补洞大小 | 0.005 |

## 🔧 参数调整建议

1. **如果点云太稀疏或太密集**：
   - 调整 `step` 参数（深度图转点云）
   - 调整 `leafsize` 参数（点云滤波）

2. **如果网格有空洞**：
   - 增大 `holesize` 参数
   - 减小 `searchradius` 参数

3. **如果网格质量不好**：
   - 尝试切换 `reconstruct=2`（贪婪投影）
   - 调整 `kSearch` 和 `searchradius`

## ⚠️ 注意事项

1. **文件命名规则**：
   - 深度图：`X.tiff_re.tiff` 或 `X.tiff`
   - RGB图：`fX.jpg`
   - 程序会自动匹配对应的文件对

2. **配置文件路径**：
   - 可以使用绝对路径或相对路径
   - 确保配置文件存在且格式正确

3. **处理顺序**：
   - 必须按顺序执行：深度图转点云 → 点云转网格 → 网格贴图
   - 每一步的输出是下一步的输入

4. **内存和性能**：
   - 大文件处理可能需要较长时间
   - 确保有足够的磁盘空间存储中间文件

## 🐛 常见问题

**Q: 提示"RGB图文件不存在"**
- A: 检查RGB图文件名是否为 `f{数字}.jpg` 格式，例如 `f0.jpg`

**Q: 生成的点云文件为空**
- A: 检查深度图格式是否正确，可能需要调整 `label` 和 `step` 参数

**Q: 网格重建失败**
- A: 检查点云文件是否正常，尝试调整 `reconstruct` 参数或算法参数
