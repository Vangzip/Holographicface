# Point Cloud 项目结构说明

## 📋 项目概述

`point_cloud` 文件夹是一个**3D点云处理和网格重建**的项目，主要用于：
- **深度图转点云**：将深度图像转换为3D点云数据
- **点云转网格(Mesh)**：使用泊松重建或贪婪投影三角化算法将点云转换为3D网格
- **网格贴图**：为3D网格模型生成纹理贴图，生成最终的3D模型

## 🗂️ 核心目录结构

### 1. **point_cloud/** - 主工程目录
这是项目的核心处理模块，包含：

#### 主要类文件：
- **`ConverPointCloud.h/cpp`** - 点云转换和网格重建的核心类
  - `meshAPI()`: 点云转网格的接口
  - `modelAPI()`: 网格贴图生成模型的接口
  - `createPoissonMesh()`: 使用泊松算法生成网格
  - `createGreedMesh()`: 使用贪婪投影三角化生成网格
  - `fillHole()`: 网格补洞功能

- **`depth_io.h/cpp`** - 深度图处理类
  - `depthToPlyColor()`: 深度图+RGB图转PLY点云文件

- **`OdmTexturing.hpp/cpp`** - 纹理贴图类
  - 为网格模型生成纹理贴图

- **`poissonmesh.hpp/cpp`** - 泊松网格处理
  - 泊松重建相关的网格处理

#### 主程序：
- **`main.cpp`** - 程序入口
  - 支持命令行参数：`-model` 和 `-config`
  - `meshFunc()`: 批量处理点云文件生成网格
  - `modelFunc()`: 批量处理网格文件生成贴图模型

### 2. **base/** - 基础工具库
- **`FileLibrary.h/cpp`** - 文件操作工具类
  - 文件/目录存在性检查
  - 路径操作（组合、转换、获取文件名等）
  - 文件遍历、复制等功能

- **`base.h`** - PCL点云库基础头文件
- **`pclbase.h/cpp`** - PCL相关基础功能

### 3. **其他子工程目录**

- **`point_icp/`** - 点云刚性拼接（ICP算法）
- **`point_merge/`** - 点云非刚性拼接
- **`fliter_RGB/`** - 点云颜色过滤
- **`multiview/`** - 多视角模型处理
- **`virtualcamera/`** - 虚拟相机深度图转点云测试
- **`osgloadply/`** - OSG加载PLY文件测试

## 🔄 工作流程

### 典型处理流程：

```
深度图(.png) + RGB图(.png)
    ↓
[depth_io] 深度图转点云
    ↓
PLY点云文件(.ply)
    ↓
[ConverPointCloud::meshAPI] 点云转网格
    ├─ 泊松重建 (Poisson Reconstruction)
    └─ 贪婪投影三角化 (Greedy Projection Triangulation)
    ↓
网格文件(_mesh.ply)
    ↓
[ConverPointCloud::modelAPI] 网格贴图
    ↓
最终3D模型(.obj/.ply with texture)
```

## 🔧 核心算法

### 1. 点云转网格算法

#### 泊松重建 (Poisson Reconstruction)
- 文件：`ConverPointCloud::createPoissonMesh()`
- 特点：适合处理有法线的点云，能生成封闭的网格
- 参数：通过配置文件设置 `reconstruct=1`

#### 贪婪投影三角化 (Greedy Projection Triangulation)
- 文件：`ConverPointCloud::createGreedMesh()`
- 特点：适合处理有序点云，速度快
- 参数：通过配置文件设置 `reconstruct=2`

### 2. 点云预处理

- **体素滤波** (`VoxelGrid`): 降采样，减少点云数量
- **移动最小二乘法** (`MovingLeastSquares`): 平滑点云和计算法线
- **法线估计**: 使用PCA或K近邻方法计算点云法线

### 3. 网格后处理

- **补洞** (`fillHole`): 使用VTK的FillHolesFilter填充网格空洞
- **法线标准化**: 确保法线方向一致

## 📝 配置文件格式

配置文件示例（`.cfg`文件）：
```
reconstruct=1              # 1=泊松重建, 2=贪婪投影
kSearch=20                  # K近邻搜索数量
searchradius=0.01          # 搜索半径
mu=2.5                     # 最近邻距离乘子
maximumNearestNeighbors=100 # 最大最近邻数量
maximumSurfaceAngle=45      # 最大表面角度
minimumAngle=10            # 最小角度
maximumAngle=120           # 最大角度
holesize=0.005             # 补洞大小
focus=105                  # 焦距参数
leafsize=0.001             # 体素滤波大小
```

## 🚀 使用方法

### 编译
使用Visual Studio打开 `point_cloud.sln` 解决方案文件

### 运行示例

```bash
# 生成网格模型
程序名 -mesh 点云文件路径 -config 配置文件路径

# 生成贴图模型
程序名 -model 网格文件目录 -config 配置文件路径
```

1. 输入文件格式：支持 `.ply` 格式的点云文件

4. 参数调优：不同场景需要调整配置文件中的参数
